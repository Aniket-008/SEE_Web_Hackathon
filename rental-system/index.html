💡 How the Rental System Works:

1. Register Properties:

Add properties along with address, monthly rent, security deposit, and landlord details.

2. Register Tenants:

Enter tenant credentials, ID documents (Aadhaar / PAN / Passport), and emergency contact.

3. Create Agreement:

Select property and tenant to generate 11-month or customized rental agreement with auto status tracking.

4. Digital Contract:

View, print, or terminate agreements. When terminated, properties automatically become available again.
